# Art direction — заметки для приёмки

Дополнение к `art-direction.json` (520 слов, 26 категорий × 20).
Спека собирается из `spec/scenes_01..06.py` скриптом `spec/build.py`; он же
валидирует: полное совпадение со `categories.json`, уникальность slug внутри
категории, длину сцены 8–16 слов, отсутствие цифр, слов «text/letters/numbers»
и стилевых прилагательных (`beautiful`, `stylized`, `cute` и т. п.).

Ниже — 20 слов, где картинка рискует быть неузнаваемой или неверно прочитанной.
Формат: **слово** (`категория`) — чем рискованно → как решено.

1. **joy** (`emotions`) — абстракция, тянет нарисовать «предмет с лицом» → поза: прыжок с поднятыми руками, солнце как единственный опорный предмет.
2. **pride** (`emotions`) — соседствует с `victory` и `champion`, легко получить второй кубок → персонаж полирует маленькую медаль на груди, кубка в кадре нет.
3. **trust** (`emotions`) — нет предмета, легко скатиться в «двое обнимаются» (= дружба) → падение назад в открытые руки второго персонажа, поза читается как акт доверия.
4. **gratitude** (`emotions`) — дублировала `grateful` из `politeness` → здесь подарок двумя руками с поклоном, а `grateful` — руки на сердце, глаза закрыты.
5. **hope** (`emotions`) — росток в горшке читается как «растение» → росток из треснувшего горшка в руках, трещина = «вопреки».
6. **patience** (`personality`) — абстракция без жеста → ожидание у медленно наполняющихся песочных часов (по брифу), поза спокойная, без часов-циферблата.
7. **respect** (`politeness`) — абстракция, легко спутать с `polite` и `manners` → уступает место старшему персонажу, опора — стул; `polite` — поклон, `manners` — придержал дверь.
8. **bug** (`technology`) — омоним «жук / ошибка в программе»; перевод «ошибка в программе» → жук сидит на плате с проводами: метафора читается, насекомое не теряется.
9. **quarter** (`time`) — омоним «четверть часа / четверть пирога»; пример про время, но цифры и циферблат запрещены → круглый пирог на четыре равные части, одна поднята.
10. **season** (`kitchen`) — омоним «время года / приправлять»; перевод — глагол → перечница над куском мяса, без календаря и листвы.
11. **change** (`money`) — омоним «изменение / сдача»; перевод «сдача» → монеты на открытой ладони рядом с бумажным слипом.
12. **interest** (`money`) — омоним «интерес / проценты»; перевод «проценты» → стопка монет растёт вверх, рядом короткая стрелка.
13. **bill** (`money`) — омоним «клюв / счёт»; пример «split the bill» → сложенный листок на блюдце между двумя чашками, без купюр.
14. **match** (`sport`) — омоним «спичка / матч»; перевод «матч» → двое персонажей и один мяч у двух ворот.
15. **score** (`sport`) — счёт невозможно показать без цифр → мяч в сетке и поднятые руки игрока; табло в кадре нет вообще.
16. **symptom** (`health`) — термометр неизбежно несёт шкалу с цифрами → термометр во рту, акцент на красных щеках; шкалу рисовать запрещено.
17. **decade** (`time`) — длительность без цифр и без подписи → пень с десятью кольцами рядом с молодым саженцем.
18. **meanwhile** (`time`) — «тем временем» провоцирует коллаж из двух кадров, а коллажи запрещены → оба действия в одной комнате: один готовит, второй ждёт.
19. **raise** (`family`) — омоним «поднимать / воспитывать»; перевод «воспитывать» → взрослый читает книжку маленькому, а не поднимает его на плечи.
20. **adopt** (`family`) — юридическое понятие, тянет на «собаку из приюта» → взрослый держит за руку нового маленького персонажа.

Отдельно про пары, которые намеренно почти зеркальны и не являются дублями:
`left`/`right`, `north`/`south`, `download`/`upload`, `entrance`/`exit` —
различаются только направлением, это ожидаемо для категории `directions`
и `technology`.
