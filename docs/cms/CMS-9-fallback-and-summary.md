# CMS-9: Fallback новостей и итог по всем волнам

## Дефект, который видел конечный пользователь

Человек выбирал в онбординге «Спорт» и «Технологии» → блок «Новости для тебя»
**исчезал полностью**, хотя новости есть.

Причина: источник (News in Levels) не размечает рубрики. В базе всего две
темы — `news` (7) и `interesting` (3). Фильтр `matchesInterests` отсекал всё,
а совпадать было не с чем.

## Решение: fallback на свежий микс

```
eligible = всё, что не скрыто и имеет валидный уровень
matched  = eligible, прошедшее фильтр интересов
chosen   = matched.length > 0 ? matched : eligible
```

**Персонализация не размывается.** Как только хоть одна новость совпала по
теме — показываем ТОЛЬКО совпавшие. Fallback включается лишь при полном промахе.

**«Не выбирал темы» ≠ «выбрал, но не совпало».** Пустой набор интересов даёт
совпадение со всем, поэтому `matched` не пуст и fallback не срабатывает. Это
разные состояния, и склеить их значило потерять возможность их различать.

## Обновлённый старый тест

Тест «всё отфильтровалось интересами — блока нет» утверждал ровно то поведение,
которое оказалось дефектом. Изменён осознанно, с комментарием почему — а не
удалён.

## Проверено вживую

Пользователь с интересами `sport`/`tech` (заведомый промах):

```
API отдаёт 5 новостей, темы у всех ["news"]
дашборд: ошибки нет, блок «Новости для тебя» виден, 5 карточек
```

То же для пользователя без интересов — тоже 5 карточек (это не fallback, а
нормальное поведение).

## Что потребовало живого прогона

Пять дефектов не ловились ни тестами, ни `tsc`:

1. **`RssNewsSource` не зарегистрирован в DI** — фоновый fetcher работал
   вхолостую: новостей нет, ошибок нет.
2. **Фронт звал `/api/next/news`, бэкенд сделал `/api/news/for-me`** — блок
   не появлялся.
3. **`topics`: строка в базе, массив в API** — дашборд падал в error boundary
   у каждого нового пользователя.
4. **Fallback новостей** — пустой блок при живых новостях.
5. **`next build` сносит dev-бандлы** — форма входа уходила GET-запросом
   с паролем в адресной строке.

Все — на стыках слоёв, где каждый агент видел свой контракт корректным.
