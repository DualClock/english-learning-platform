# Как запустить и протестить

Один запуск — API, база и фронт. Дальше админка доступна в браузере,
и правки в ней сразу видны обычному пользователю.

## Что должно быть запущено

1. **Docker Desktop** — вручную (демон не стартует сам). Внутри него контейнер
   `english_platform_db` (Postgres 16 на порту 5433).

   ```bash
   docker ps | grep english_platform_db
   ```

   Если пусто:
   ```bash
   cd /c/Users/Nikita/Desktop/EnglishLearningPlatform
   docker compose up -d
   ```

2. **API** — http://127.0.0.1:5226

   ```bash
   cd /c/Users/Nikita/Desktop/EnglishLearningPlatform
   ASPNETCORE_ENVIRONMENT=Development \
   ASPNETCORE_URLS=http://127.0.0.1:5226 \
   Admin__BootstrapEmail=nik@mail.com \
   dotnet run --project EnglishLearningPlatform.API
   ```

   `Admin__BootstrapEmail` — критично. Он выдаёт роль Admin аккаунту
   `nik@mail.com` при старте. Без него админка не откроется ни у кого:
   ролей в базе не будет.

   Проверка: `curl http://127.0.0.1:5226/health` → `{"status":"ok"}`.
   В логе старта должна быть строка `Роли: создано 2, ...`.

3. **Фронт** — http://localhost:3000

   ```bash
   cd /c/Users/Nikita/Desktop/EnglishLearningPlatform/frontend
   npm run dev
   ```

## Как зайти в админку

1. Открой http://localhost:3000/login
2. Войди как **`admin@lexicon.local`**, пароль **`7PQVucBrU7tn`**
   (или как `nik@mail.com`, если помнишь его пароль — роль Admin есть у обоих).
3. В левом меню **первым блоком** появится **«АДМИНКА»** с пунктами
   «Категории и слова» и «Книги». Кликай по ним.

Пункт стоит первым намеренно: меню обычного человека занимает почти всю высоту
экрана, и в конце ссылка уходила за прокрутку — админ видел обычное меню и
решал, что функций админа нет.

Обычный пользователь на адресе `/admin/*` получит **404**: middleware проверяет
роль в сессии, а не только прячет ссылку. Если он дёрнет API напрямую — **403**.

## Что можно проверить руками

### Категории и слова — `/admin/content/categories`

- Создать категорию: введи имя, «Создать». Слаг делается сам —
  русское имя транслитерируется («Проверка UI» → `proverka-ui`).
- Добавить слово: выбери категорию слева, заполни «Слово» и «Перевод»
  (транскрипция и пример — необязательны), «Добавить слово».
- Удалить слово: кнопка «Удалить» в строке. Удаление мягкое — слово
  уходит из выдачи, но прогресс пользователей по нему сохраняется.
- Галочка **«Показать удалённые»** показывает удалённое и даёт кнопку
  «Восстановить».

### Книги — `/admin/content`

- **«Загрузить EPUB»** — кнопка в шапке страницы. Книга попадает сразу в
  **общий каталог** (без владельца), поэтому её видят все, включая
  незарегистрированных на `/library`. Пользовательская загрузка из
  «Библиотеки» работает иначе: та книга остаётся личной.
- «Опубликовать» делает публичной уже существующую личную книгу.
- «Удалить» — мягкое, прогресс чтения сохраняется.

### Картинки слов — `/admin/content/categories`

В таблице слов у каждого слова слева квадрат: «нет» (пунктир) или загруженная
картинка. Под транскрипцией — ссылка **«Добавить фото»** / «Заменить фото»,
рядом «Убрать».

Что делает сервер при загрузке (не UI):

- принимает JPG, PNG, WebP, GIF до **8 МБ**;
- проверяет, что это действительно картинка — по содержимому, а не по
  расширению: «скрипт с именем .png» отклоняется и на диск не попадает;
- пересохраняет в **WebP** и урезает до 512 px по большей стороне
  (карточка показывает до 208 px);
- имя файла генерирует сам.

Картинка видна пользователю в карточке слова на `/categories/<slug>` и
приоритетнее статической иллюстрации.

### Загрузка файлов из консоли

```bash
curl -X POST http://127.0.0.1:5226/api/admin/content/words/<ID>/image \
  -H "Authorization: Bearer $TOKEN" -F "file=@photo.jpg"
```

### Как убедиться, что пользователь это видит

Открой в другом браузере (или в инкогнито) обычный аккаунт и зайди на
**/categories**. Категория и слова, добавленные админом, будут там же.
Удалённое — исчезнет.

Кэш витрин сбрасывается при каждом сохранении, поэтому обновлять страницу
с `Ctrl+Shift+R` не нужно.

## Если что-то не открывается

| Симптом | Причина | Что делать |
|---|---|---|
| `/admin` отдаёт 404 под админом | middleware не смог прочитать сессию | проверь `NEXTAUTH_SECRET` в `frontend/.env.local` |
| `/admin` отдаёт 404 у `nik@mail.com` | роли нет в базе | перезапусти API с `Admin__BootstrapEmail=nik@mail.com` |
| «Нужны права администратора» на странице | токен получен до выдачи роли | выйди и войди заново — роль читается при логине |
| `HTTP 429` в админке | исчерпан лимит админских запросов | лимит 240/мин на пользователя; подожди минуту |
| API не стартует, `MSB3027` | старая копия API держит файл | `powershell -NoProfile -Command "Get-Process -Name EnglishLearningPlatform.API \| Stop-Process -Force"` |
| Категории пустые | сиды не отработали | смотри лог старта API на строку «Сиды:» |
