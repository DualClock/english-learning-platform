# Пак озвучки слов (`uploads/tts-pack`)

Предгенерация озвучки 4500 слов словаря нейроголосом Microsoft Edge (AriaNeural).
Файлы кладутся на сервер один раз, и клик по слову перестаёт зависеть от квоты
провайдера, от его доступности и от задержки 3–6 с.

## Зачем

`SpeechService.SynthesizeAsync` (бэкенд) смотрит в пак **первым**, до кэшей и до
провайдеров. Пока в паке есть файл, ни Gemini, ни Azure не вызываются:

| Источник | Ограничение | Что даёт пак |
|---|---|---|
| Gemini TTS | 100 запросов/сутки на модель | 4500 слов = 45 суток бесплатной квоты |
| Azure Speech | 400 000 символов/месяц на весь сервис | весь словарь = 28 549 символов (7,1 % бюджета) |
| Задержка | 0,4–6 с на слово | `<audio>` с готовым файлом |

Ещё один эффект: пак не тратит время сервера. Полный прогон Gemini по словарю
занимал бы 4500 последовательных ожиданий; файл с диска отдаётся за миллисекунды.

## Формат файла — контракт с бэкендом

Имя файла = `sha256("pack|" + слово) + ".mp3"`, где слово приведено к нижнему
регистру и пробелы схлопнуты. Хэш считается как **`hex` в нижнем регистре**
(64 символа), это именно то, что делает `SpeechService.FindPackFile`.

Ключ всегда из нижнего регистра, потому что `FindPackFile` пробует два варианта:
слово как есть (`Alice` из книги) и в нижнем регистре (`alice` из словаря) — оба
указывают на один файл.

Соответствие проверяется дважды:
- `EnglishLearningPlatform.API.Tests/SpeechPackTests.cs` — хэш на стороне C#;
- прогон генератора на реальном сиде сверен с формулой независимым скриптом
  (30 пилотных слов, имена совпали 30/30).

## Использование

```bash
pip install edge-tts

# 1. прикидка: сколько файлов не хватает, сколько это места и минуты звука
python tools/tts-pack/generate.py \
    --words EnglishLearningPlatform.API/Data/Seed/wordlists.json \
    --out EnglishLearningPlatform.API/uploads/tts-pack \
    --dry-run

# 2. пилот (первые 30 слов: A1, rank 1–30)
python tools/tts-pack/generate.py --words ... --out ... --limit 30

# 3. полный прогон — прерывать и перезапускать можно в любой момент
python tools/tts-pack/generate.py --words ... --out ...
```

`--words` принимает и `wordlists.json` (`{wordLevels: [{text, cefr, rank}]}`), и
обычный txt со словом в каждой строке.

## Устойчивость и валидация

- **Рестарт с места обрыва**: файл, прошедший валидацию, пропускается. Повторный
  запуск полного прогона ничего не перегенерирует.
- **Огрызки перезаписываются**: существующий, но битый файл удаляется и
  создаётся заново. Раньше проверялся только размер `> 1024`, поэтому HTML-заглушка
  размера 2 КБ считалась готовой озвучкой.
- **Запись через `.tmp`**: звук сначала пишется в `<имя>.mp3.tmp`, проверяется и
  только потом переименовывается. Ctrl+C посреди прогона не оставит в паке
  половину файла, которую следующий запуск примет за готовую.
- **Валидация каждого файла**: размер > 1 КБ, длительность > 0,3 с. Длительность
  считается разбором MP3-кадров, без внешних зависимостей — поэтому файл ровно
  нужного размера, но с обрезанным потоком, отбраковывается.
- **Брак не роняет прогон**: ошибка по слову печатается сразу и уходит в счётчик,
  остальные слова продолжают генерироваться. Код возврата 1, если брак был.
- **Прогресс**: раз в 25 файлов — счётчик, доля, скорость (слов/с) и ETA.

## Замер (Windows, `--concurrency 8`)

| Метрика | Значение |
|---|---|
| Пилот, 30 слов | 4,96 с (6,1 слов/с), 368 КБ |
| Калибровка, 120 слов | 16,4 с (7,7 слов/с), 1,5 МБ |
| Средний файл | ~12,8 КБ, 1,66–1,87 с звука |
| Полный пак 4500 | ~10 мин чистой генерации, ~14 мин с запасом на повторы, ~56 МБ |

Пак 4500 слов стоит $0: Edge-TTS бесплатен и не требует ключа. Для сравнения,
те же 28 549 символов через Azure по $16/1M — около $0,46, но Azure-бюджета
хватило бы, потому что лимит считается не по деньгам, а по 400 000 символов в
месяц на весь сервис, и его тратит озвучка глав читалки.

## Что проверять после полного прогона

```bash
find EnglishLearningPlatform.API/uploads/tts-pack -type f | wc -l   # ожидаемо 4500
du -sh EnglishLearningPlatform.API/uploads/tts-pack                  # ожидаемо ~56M
```

`find` не должен находить `*.tmp`. Если файлов меньше — запустить прогон ещё раз:
он доберёт только недостающие.
