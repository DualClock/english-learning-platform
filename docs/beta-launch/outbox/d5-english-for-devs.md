# d5 · english-for-devs — питч админу читательского TG-канала

**Адресат и канал.** [English for Developers](https://t.me/englishfordeveloper), 11.8K, активен (23.10.2026) — из семи читательских каналов при 0 ₽ остался единственный живой и потенциально доступный. Контакта админа в реестре нет: сначала найти контакт в закреплённом посте канала, потом писать.

**Почему этот канал и интент аудитории.** Аудитория — разработчики, учившие английский и застрявшие на «читаю документацию, не могу прочитать книгу». Интент читательского канала — книги и чтение ради текста, не методичка. Поэтому заход про книгу и про то, что не надо выпадать в словарь, а не про уроки. админу даём тему для подписчиков, а не рекламу.

## ИТОГОВЫЙ текст письма админу (править только имя; писать после того, как нашли контакт)

Здравствуйте! Нашёл контакт в закрепе [Имя канала] — пишу по делу, коротко.

Я делаю Lexicon, читалку английских книг, и ваша аудитория ровно в целевой: технари, которые читают стэк-оверфлоу, но спотыкаются о «Холмса» или «Моби Дика». Показываю сразу, без регистрации и без демо-логина: Холмс — страница [ДОМЕН]/library/the-adventures-of-sherlock-holmes, «Моби Дик» — [ДОМЕН]/library/moby-dick, вся полка по уровням A1–C1 — [ДОМЕН]/library. Механика простая: текст на экране, кликаешь незнакомое слово — перевод выпрыгивает рядом, без копирования во вкладку; слово уходит в словарь и возвращается на повторение само (на следующий день, потом через шесть дней, дальше длиннее; забыл — через десять минут). Клики по словам живут в читалке, то есть уже с аккаунтом; на витрине — первые 150 слов книги. Свои EPUB грузятся из «Библиотеки». Бесплатная бета до 2 ноября, без карты; с тестера прошу два коротких ответа за 14 дней — первый собирается сам в приложении (одна кнопка под прочитанной страницей, не анкета), второй коротким сообщением в конце когорты.

Не втюхиваю пост. Две опции на выбор: 1) дам тему для вашего канала — как читать аутентичную книгу и не бросить, со скринкастом, где видно клик по слову; 2) закреплю ссылку вида [ДОМЕН]/t/english-for-devs — по ней видно, сколько регистраций пришло от вас, сводку верну вам. Промокода, открывающего доступ, сейчас нет — только атрибуция, говорю как есть. Если канал берёт рекламу и цена кусается — обсудим бартер вместо денег.

## Второй вариант первой строки (A/B)

> [Имя], здравствуйте! У вас читательский канал про английский для технарей — у меня как раз читалка книг с переводом по клику. Не прошу рекламу, предлагаю тему для ленты или закреплённую ссылку со статистикой вам.

## Что приложить

Из `materials/` для читательского канала ничего не прикладываем (рабочий лист — учительский материал). Если админ попросит демо — готовим кадры по `materials/screencast-storyboard.md`, публикуем только после GO.

## Чего в этом тексте быть не должно

Не обещать мобильное приложение, озвучку глав и транскрипции: в бете их нет; не выдумывать домен.

## Что проверить перед отправкой

1. Найти реальный контакт админа в закрепе канала — без него письмо не уходит.
2. Подставить домен; проверить `/t/english-for-devs` и что клик-перевод реально работает на стенде в пределах AI-лимита.
3. Не публиковать ничего до подписи GO — статус «ждёт контакта + GO».
4. Страницы книги открываются анонимно на стенде: `[ДОМЕН]/library/the-adventures-of-sherlock-holmes` и `[ДОМЕН]/library/moby-dick` отдают 200 без сессии, 150 слов превью видны в HTML без JS — письмо начинается именно с них, поэтому они должны быть живыми до первой отправки.
