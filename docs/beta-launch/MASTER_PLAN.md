## 2. Волны запуска

Волна — это пакет агентов, который стартует вместе и заканчивается вместе. Волна N+1 не
начинается, пока у волны N не закрыты критерии приёмки. Волны 0 и 1 можно перекрывать руками,
кодами и материалами.

**Волна 0 — Разведка (read-only, 2 агента, ~30 минут).** Нужна, чтобы не чинить то, чего нет
в проде. Блокировка: URL от тебя.
**Волна 1 — Гейт (3 агента, 1–2 дня).** Всё, что должно быть правда, прежде чем мы зовём чужих.
**Волна 2 — Воронка (3 агента, 1–2 дня).** Измеримость, точка входа, индексация, материалы.
**Волна 3 — Посев (2 агента, непрерывно с 28.10).** Договорённости, посты, видео, ответы.
**Волна 4 — Когорта (3 агента, с 02.11).** Фидбек, цифры, отчёт, решения.

## 3. Агенты, их скиллы и границы

Каждый агент вызывает свои скиллы по имени, пишет только в свою зону файлов (§4) и приносит
артефакт, а не пересказ. Ни один агент не отправляет сообщения от твоего имени, не деплоит и
не публикует без твоего «публикуй».

### Волна 0

**W0.1 Deploy Sentinel.**
Миссия: установить правду о проде. Вход: URL фронта и API. Инструменты: `tinyfish:fetch`,
`browser-use`/`playwright` MCP (заголовок-матрица, robots/sitemap, `/_next/image`, OG-превью,
404, http→https), `Bash` (curl -I), `architecture-visualization:deployment-topology-analyzer`
для связки «репозиторий → билд → хостинг».
Выход: `docs/beta-launch/PROD_TRUTH.md` — таблица «факт / evidence / расхождение с ожиданиями»,
включая ответ, из какой ветки собран прод, и список того, чего там не хватает.
Критерий приёмки: каждый вывод имеет команду-повтор и дату; нет ни одного «по-видимому».

**W0.2 Channel Ops.**
Миссия: довести реестр каналов до статуса «можно писать сегодня». Скиллы: `tinyfish:search`,

## 7. Что делаем, если план ломается

Не дали URL к 24.10 — Волна 0 не стартует, Волна 1 идёт по коду, GO отодвигается, публикация
сдвигается день в день; переговоры не останавливаем.
Бюджет 0 ₽ — Path A (посевы) выпадает, план держится на учителях, Product Radar, Дзене и
видео; ожидаемо 90–120 регистраций вместо 170–210, цель по активным не снижается.
Упёрлись в лимит агентов (уже случалось 23.10: один агент упал на дневном квоте) — агент
перезапускается в следующей волне, а при повторном отказе его объём делает менеджер прямыми
инструментами, и это фиксируется в отчёте как невыполненная агентская работа.
D7 когорты < 10% — посевы останавливаем, вся Волна 4 перенацеливается на онбординг и первую
главу, потому что трафик в дырявый продукт — это сожжённые контакты.
Админы каналов отказали всем — переходим на преподавательский обход (10 личных диалогов) и
собственные площадки; Reddit и PH включаются только после EN-локализации.

## 8. Решения (статус на 23.10, вечер)

1. **План подтверждён**, волны 0 и 1 запущены.
2. **Бюджет: 0 ₽.** Значит Path A (платные посевы) из математики выпадает: ожидаемо 90–120
   регистраций вместо 170–210, упор на учителей, Product Radar, Дзен и свои ролики. Цель по
   активным (60) и по отзывам (40) не снижается.
3. **Вариант релиза A1 изменён по факту проверки.** «Security-десять первыми на main»
   неприменим: `git apply --check` на `origin/main` даёт отсутствующие файлы
   (`CategoriesController.cs`, `FeedbackController.cs`, `admin/feedback/AdminFeedbackClient.tsx`)
   и конфликты в `Program.cs`, `AuthController.cs`, `ProfileController.cs`, `BookService.cs`,
   `DEPLOY.md`, `.gitignore` — эти фичи появились уже после main. Работаем на
   `release/beta` = `3b8cb29` (все десять фиксов внутри), редизайн покрывается ручным
   смоук-тестом по сценарию из §5.
4. **По-прежнему нужен URL прода** — без него Волна 0 (Deploy Sentinel) и GO-чеклист по живому
   сайту не выполняются; без них публикация остаётся закрытой.
