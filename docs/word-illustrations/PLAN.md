# Иллюстрации для карточек слов — план

Статус: **пилот**. Стиль утверждается на 1 слове, потом массовое производство.

## 1. Что есть сейчас (факты из кода)

| Что | Где | Состояние |
|---|---|---|
| 520 слов, 26 категорий × 20 | `EnglishLearningPlatform.API/Data/Seed/categories.json` | есть |
| Модель `CategoryWord` | `Models/Category.cs` | полей `ImageUrl`/`Visual` **нет** |
| Экран категории, 4 режима | `frontend/src/app/categories/[slug]/page.tsx` | иллюстраций нет |
| Личный словарь: emoji/upload | `Services/WordImageService.cs`, `WordVisualCatalog.cs`, `UserWord.ImageUrl` | есть, но к категориям не относится |
| Раздача статики API | `Program.cs` → только `/uploads/covers` | для картинок слов не настроено |
| Бренд-палитра | `frontend/src/app/globals.css` (`--color-lexi-*`, `--color-tint-*`) | есть |
| Маскот Lexi | `frontend/public/brand/lexi-mark.svg` | кремовая бумага + чернильный контур `#17314C` + румянец `#F3B39B` |

## 2. Решение по архитектуре

**Картинки — статические ассеты фронтенда, БД не трогаем.**

```
frontend/public/words/<category-slug>/<word-slug>.webp   (512×512, ~30–50 КБ)
frontend/src/lib/wordIllustrations.generated.ts          (манифест: какие файлы есть)
```

Почему так:
- нет миграции EF, нет изменений в API, нет риска для `release/beta`;
- статика отдаётся тем же origin → CSP (`frame-ancestors 'none'`) не мешает;
- манифест = единственный источник правды: пока картинки нет, компонент рендерит
  прежний текстовый вид, а не битую картинку и не 404 в консоли.

Отвергнутые варианты:
- *колонка `ImageUrl` в `CategoryWord`* — миграция + сидер + API ради того, что
  можно вывести из slug. Вернёмся, если картинки станут редактируемыми из админки.
- *`uploads/` на API* — требует `UseStaticFiles` + авторизации/прокси, ассеты
  перестают ехать вместе с фронтендом.

## 3. Стиль: «Lexi-card» — утверждён вариант **B, без контура**

База — рецепт флеш-карточек Kimi (восковая текстура, кавайное лицо, один объект
по центру, много воздуха). Палитра привязана к бренду, но **без обводки**:
силуэт держится плотностью заливки, как в оригинальном наборе.

Фиксированные параметры (не меняются от картинки к картинке):
- один объект по центру, занимает ~70% кадра, поля одинаковые;
- восковая/гуашевая зернистая заливка, **без градиентов и теней, без контуров**;
- лицо: две точки-глаза, маленькая улыбка, два овальных румянца `#F3B39B`;
- палитра: крем `#FFF2D8`, терракота `#E08A5F`, шалфей `#9BBF8A`,
  роза `#F3B39B`, тил `#0E7C7B` акцентом. Мягко, но с читаемым контрастом —
  картинка должна узнаваться на 56 px;
- фон — **чистый белый**: совпадает с `bg-canvas` карточки, и в светлой теме
  лист растворяется в ней; в тёмной получает тонкое световое ребро (стикер);
- запрещено: текст, буквы, водяные знаки, рамки, коллажи, фотореализм, 3D-рендер.

Отвергнутый вариант **A «Lexi»** (тонкий чернильный контур `#17314C`, бумажный
фон) — лучше держал мелкий размер, но выглядел как чужой набор рядом с маскотом.
Оставлен в `style-test/` на случай, если понадобится более «продуктовый» тон.

## 4. Пайплайн (агент-иллюстратор)

1. **Спека** — на каждое слово: тип (объект / действие / абстракция / черта
   характера / место) + предметная сцена. Абстракции (`joy`, `patience`, `money`)
   рисуются сценой или метафорой, а не «предметом с лицом».
2. **Генерация** — промпт = фиксированный шаблон + сцена из спеки.
3. **Нормализация** — обрезка фона по bbox, вписывание в квадрат с равными полями,
   ресайз 512×512, WebP q88. Скрипт: `tools/prepare_card.py`.
4. **Публикация** — файл в `frontend/public/words/<cat>/<word>.webp` + строка в манифесте.
5. **QA** — контактный лист категории, проверка: палитра, поля, нет текста,
   лицо читается, объект узнаваем без подписи.

## 5. Порядок работ

| Фаза | Объём | Результат |
|---|---|---|
| 0. Пилот стиля | 1 слово × 2 варианта | выбор A/B |
| 1. Пилот категории | 20 картинок (`food`) | контактный лист + вёрстка в UI |
| 2. Интеграция | компонент + манифест + 2 экрана | картинки в проде, fallback работает |
| 3. Массово | 26 категорий, волнами по 20 | 520 картинок |
| 4. Полировка | QA всех категорий | единый набор |

## 6. Стоимость

Генерация — платная: ~5–10 кредитов за картинку.
- пилот (1 + 20) ≈ 105–210 кредитов;
- весь набор 520 ≈ **2 600–5 200 кредитов**.

Поэтому: сначала пилот, потом решение о масштабе. Порядок категорий — по
«рисуемости»: сначала предметные (food, animals, clothes, transport, home,
kitchen), абстрактные (politeness, personality, communication) — последними.
