## Что уже сделано — НЕ переделывай

1. **520 иллюстраций**: `frontend/public/words/<category-slug>/<word-slug>.webp`
   - 26 категорий × 20 слов, все 512×512 WebP, суммарно ~12 МБ.
   - Стиль «Lexi-card»: восковая заливка, кавайное лицо, **без контуров**, чистый белый фон.
   - Имена файлов — строго `[a-z0-9-]`, совпадают с `slug` из `docs/word-illustrations/art-direction.json`.
2. **Манифест**: `frontend/src/lib/wordIllustrations.generated.ts` — **сгенерированный** файл (520 ключей).  
   Экспортирует: `hasIllustration(categorySlug, word)`, `illustrationSrc(categorySlug, word)`, `slugifyWord(word)`.  
   **Руками не редактировать** — перезаписывается скриптом.
3. **Компонент**: `frontend/src/components/dictionary/WordIllustration.tsx`
   - props: `categorySlug`, `word`, `translation?`, `alt?`, `size: 'sm'|'md'|'lg'`, `className?`, `placeholder?`;
   - размеры: `sm` 56 px (список), `lg` 208 px (флэшкарта);
   - если в манифесте ключа нет — рендерит `null`, а не битую картинку;
   - `loading="lazy"`, `decoding="async"`, фиксированные `width`/`height` (без layout shift).
4. **Вёрстка уже подключена** в `frontend/src/app/categories/[slug]/page.tsx`:
   - режим «Слова» — иллюстрация `sm` слева от текста;
   - режим «Флэшкарты» — `lg` над словом; на обороте картинка скрыта, но слот того же размера остаётся, чтобы карточка не прыгала по высоте;
   - режимы «Угадай перевод» и «Выбери вариант» — **картинки нет намеренно** (она подсказывает ответ).
5. **Токен темы**: `--color-illustration-paper: #FFFFFF` в `frontend/src/app/globals.css` (светлая и тёмная темы) + `tailwind.config.ts` → `bg-illustration-paper`. В тёмной теме у тайла тонкое световое ребро (`.word-illustration-tile`).
6. `npx tsc --noEmit` проходит без ошибок.

## Что нужно сделать тебе

**1. Проверка в живом интерфейсе (главное).**  
Запусти `cd frontend && npm run dev`, залогинься, открой `/categories/food`, `/categories/emotions`, `/categories/animals` и пройди все четыре режима в **светлой и тёмной** теме. Проверь:

- иллюстрации видны, не растянуты, не обрезаны, фон тайла не выделяется прямоугольником в светлой теме;
- в тёмной теме белый лист читается как стикер, а не как засветка;
- при перевороте флэшкарты высота карточки не меняется и кнопки «Знаю / Не знаю» не уезжают;
- в режимах «Угадай перевод» и «Выбери вариант» картинки **не появились**;
- в консоли **нет 404** на `.webp`.

**2. Устойчивость к отсутствию картинки.**  
Временно переименуй любой файл (например `frontend/public/words/food/appetite.webp` → `.bak`), обнови страницу: строка списка не должна прыгать и не должно быть битой иконки. Верни файл обратно. Помни: манифест статичен, поэтому при удалении файла без пересборки манифеста браузер всё равно запросит `.webp` — этот сценарий тоже проверь и опиши в отчёте.

**3. Вес и загрузка.**  
Убедись, что 520 картинок не грузятся разом: в Network при открытии категории должно быть ~20 запросов, а не 520. Если `loading="lazy"` не срабатывает (например, из-за того что картинка в первом экране) — предложи и обоснуй правку (например `fetchPriority="high"` только для флэшкарты).

**4. Прод-сборка.**  
`cd frontend && npm run build` должен проходить. Проверь, что `public/words/**` попадает в артефакт сборки и на деплое доступен по пути `/words/<cat>/<slug>.webp` (12 МБ статики — убедись, что хостинг это переваривает; если деплой на Render/Vercel — проверь лимиты).

**5. Правила добавления новых картинок.**  
Если понадобится добавить или заменить слово:

- файл кладётся только через `python docs/word-illustrations/tools/publish_category.py <category> --force` (он сам обрежет фон, впишет в квадрат и сделает WebP);
- после — `python docs/word-illustrations/tools/build_manifest.py`;
- имена файлов руками не придумывать: slug берётся из `art-direction.json`.

**6. Опционально, если увидишь смысл (согласуй перед правкой).**

- Показывать иллюстрацию в режиме «Угадай перевод» **после** проверки ответа, как награду;
- добавить иллюстрации в другие экраны, где перечисляются слова категорий (если такие найдутся).

## Жёсткие ограничения

- **Не трогай** `EnglishLearningPlatform.API/` (модели, контроллеры, EF-миграции) и `Data/Seed/categories.json`. Иллюстрации живут как статика фронтенда, БД для них не нужна.
- **Не редактируй** `wordIllustrations.generated.ts` руками и не меняй его API — компонент и страница на него завязаны.
- **Не переименовывай** файлы в `public/words` и не меняй структуру папок: ключ манифеста = `<category>/<word>`.
- **Не генерируй** новые картинки: это отдельный пайплайн, он тратит платные кредиты.
- **Не коммить** в `release/beta` без явного разрешения. Покажи дифф и дождись ответа.
- Комментарии в коде — по-русски, в стиле проекта: объясняй **почему** так, а не что делает строка (посмотри соседние комментарии в `page.tsx` — там плотные пояснения решений).

3. В консоли нет 404 и нет ошибок гидратации.

## Известные ловушки

- Ассеты весят 12 МБ — если деплой падает по размеру, скажи об этом, не начинай сжимать картинки самостоятельно (качество согласовано).
- В `docs/word-illustrations/raw/` лежат исходники и бэкапы (`.png`), в `public/words` — только готовые `.webp`. Не тащи `.png` в `public`: это удвоит вес.
- Флэшкарта использует `ILLUSTRATION_SIZE_CLASS.lg` для пустого слота на обороте. Если будешь менять размер картинки, меняй его **в этом объекте**, иначе высота карточки начнёт прыгать.
